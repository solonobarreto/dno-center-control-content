Menu

Manual do Usuário

+ Adicionar Personagem

Clique no botão + na barra de controles para abrir a grade de classes. Escolha uma classe, digite um apelido (nickname) e confirme. O apelido precisa ser único entre todos os personagens.

× Remover Personagem

Clique no × no canto superior esquerdo da célula da classe para remover a linha daquele personagem.

+ Adicionar Conteúdo

Clique no pequeno botão + sobre o ícone da classe para abrir a lista de conteúdos e clique em um item para adicioná-lo.

✗ ✓ Marcar Conteúdo Concluído

Clique no ícone ou no texto de um chip de conteúdo para alternar entre pendente (✗) e concluído (✓).

✕ Remover Conteúdo

Clique no ✕ à direita do chip para removê-lo da linha.

Configurar Equipamento

Clique no ícone de escudo para configurar Set ou Arma: escolha o slot, a raridade (Epic, Unique, Legend), o nível (Lv80/Lv90) e o refino (+0 a +15).

Backup (Exportar / Importar)

Como os dados são armazenados apenas no navegador, eles são perdidos ao fechar a aba. Use Export para salvar um arquivo e Import para restaurar.
